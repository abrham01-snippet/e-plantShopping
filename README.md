# 🌿 e-plantShopping

A plant shopping web application built with **React**, **Redux Toolkit**, and **Vite**. This project provides an interactive shopping experience where users can explore different categories of plants, add products to their cart, and manage their shopping selections.

## Live Demo

**Visit the application:**  
https://abrham01-snippet.github.io/e-plantShopping/

##  About the Project

e-plantShopping is a frontend e-commerce project developed as part of my learning journey in web development through the IBM Skills Network program.

The application focuses on building a responsive shopping interface and implementing global state management with Redux Toolkit.

##  Features

- Browse plants across different categories.
- View plant names, images, descriptions, and prices.
- Add plants to the shopping cart.
- Increase or decrease product quantities.
- Remove products from the cart.
- Calculate individual product subtotals.
- Calculate the total cart amount.
- Navigate between the product listing and shopping cart.
- Responsive user interface.

**Note:** The checkout button is currently a placeholder for future functionality.

##  Technologies Used

- **React** – Building the user interface.
- **JavaScript (ES6+)** – Application logic.
- **Redux Toolkit** – Global state management.
- **React Redux** – Connecting React components to the Redux store.
- **Vite** – Development server and production build tool.
- **CSS** – Styling and layout.
- **Git & GitHub** – Version control and source-code hosting.
- **GitHub Pages** – Application deployment.
- **gh-pages** – Automating deployment to GitHub Pages.

##  Getting Started

Follow these instructions to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/abrham01-snippet/e-plantShopping.git
```

### 2. Navigate to the project directory

```bash
cd e-plantShopping
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

##  Build and Deployment

This project uses Vite to create a production-ready build and GitHub Pages to host the application.

### Create a production build

```bash
npm run build
```

### Deploy to GitHub Pages

```bash
npm run deploy
```

The deployment script builds the application and publishes the contents of the `dist` directory to the `gh-pages` branch.
